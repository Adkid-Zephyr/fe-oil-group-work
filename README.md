# Oil spread coursework

Forecast the weekly change in the CL2−CL1 calendar spread.

The program reads only `data/raw/Oil Data.xlsx`. The brief is `guidelines/Canvas/26 Fintech CW Financial Econometrics.pdf`.

Open `coursework/analysis.ipynb` and run it from the top. The forecast is weekly. Every series is read from `data/raw/Oil Data.xlsx`. The same estimation is `coursework/analysis.py`.

The note is `coursework/REPORT.md`. The slides are `coursework/briefing.pptx`. Results are written to `data/results/coursework/`.
