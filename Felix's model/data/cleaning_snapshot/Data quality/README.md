# Quality evidence

These files are generated by `../clean_data.py`, except this index. They describe source issues, not silent repairs.

| File | Evidence |
|---|---|
| `summary.json` | Source hash, row accounting, dates, formula counts, unresolved items |
| `manifest.json` | SHA-256 of generated CSV/JSON outputs; excludes itself |
| `data_dictionary.csv` | Original/clean names, Excel columns, units and usage restrictions |
| `source_definitions.csv` | Nonempty rows of the source definition sheet |
| `quarantined_rows.csv` | All 534 nonempty undated records, retained as original row + raw-values JSON |
| `missingness.csv` | Per-field source missingness, first/last valid dates and leading/internal/trailing counts |
| `missing_ranges.csv` | Contiguous source missing ranges; excludes the additional derived interpolation mask |
| `formula_audit.csv` | All 356 formulas, cached/recomputed values and source locations |
| `cross_frequency_comparison.csv` | Every monthly/daily comparison on the same reference date |
| `cross_frequency_summary.csv` | Match, mismatch and absent-date counts by field |
| `calendar_review.csv` | Weekdays absent from the daily date grid; not confirmed missing trading days |
| `review_flags.csv` | Negative values and full-sample large-first-difference flags, retained |
| `constant_runs.csv` | Repeated-value runs, retained |

Large-difference flags use |modified z| > 8 on first differences, using a full-sample median/MAD. They are descriptive audit evidence only: using them to filter model observations or as an ex-ante signal introduces information from the full sample. A review flag is not a finding that a value is wrong. See [the report](../CLEANING_REPORT.md) for decisions and limitations.
